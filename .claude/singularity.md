# singularity project config

Read by the shared singularity agents and pipelines, and imported into every session through CLAUDE.md, so keep it
short. **Only write overrides.** Anything you leave out uses the shared default from the singularity repo, so
improvements there keep reaching this project. [AGENTS.md](../AGENTS.md) is the project's contract and wins over
anything here.

```yaml
commands:
  install: scripts/tools.sh          # the pinned check tools; a fresh clone runs scripts/bootstrap.sh once
  build: swift build                 # also the typecheck: Swift 6 language mode, warnings fail the build
  lint: scripts/lint.sh
  test: scripts/verify.sh --no-lint  # the done check (AGENTS.md §7): build, docs against the CLI, swift test, fixtures
  test_one: swift test --filter {suite}
  # format: none, SwiftLint checks style in scripts/lint.sh and nothing rewrites code.
  # When App/ or project.yml changed, the done check is scripts/verify.sh --app; for a change
  # scripts/change-scope.sh main scopes `checks`, scripts/verify.sh --checks-only (AGENTS.md §8).

conventions:
  default_branch: main
  branch: "{type}/{slug}"   # type: fix, feat, refactor, test, docs or ci (AGENTS.md §8); never work on main
  commits: "an imperative sentence of what the change does for the user, no type prefix; squash-merged as the PR title"
  work_dir: .agentic/work
  auto_commit: false
  auto_pr: false
  breaking_changes: allowed   # AGENTS.md §1: no compatibility shims; the user's files and learned state still migrate

tracker:
  type: files               # task files named STATUS-ID-slug, e.g. TODO-T7-fix-login.md; needs singularity 0.3.0
  files:
    dir: .agentic/tasks     # git-ignored with the rest of .agentic/
    # statuses: the defaults, TODO PROGRESS REVIEW BLOCKED DONE (REVIEW: its pull request is open)
  updates: true

code_host:
  type: github              # hlistan/arrumator; pull requests follow AGENTS.md §8 and .github/pull_request_template.md

learning:
  enabled: true
  dir: .claude/singularity/experience
  max_lines_per_file: 60

optimization:
  every_runs: 10
  web_scan: true
  max_eval_cost_usd: 10
```

## Do not touch

Change the generator, never its output, and never edit these by hand:

- `Tests/Fixtures/` and its `expected.json`: generated by `Tools/FixtureGen`.
- `App/Assets.xcassets/AppIcon.appiconset/`: generated by `scripts/app-icon.sh` from `scripts/app-icon.swift`.
- `App/Info.plist` and `Arrumator.xcodeproj`: generated by `xcodegen` from `project.yml`.
- `.claude/singularity/evals/`: cases are only added; editing or deleting one is a human decision.
