# Experience

The record of this project's learning loop: what happened in each run and
each human review, and what the optimizer tried. The optimizer analyses it.
The agents doing the work don't read it: they follow the current guidelines
in `../guidelines/` and `.claude/rules/singularity/`, which say how to do
things now rather than what went wrong before.

- `runs.jsonl`: one digest line per pipeline run and per human review,
  including the guidelines each run added, changed or removed.
- `optimizations.md`: the optimizer's archive.
- `upstream.md`: guideline candidates for every project, with evidence.
